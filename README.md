# Sistema de Citas Médicas

## Instalación y configuración
Se requiere JDK 11. Ejecute el archivo FAT JAR incluido en las entregas o compile el código fuente usando IntelliJ IDEA.

## Uso del programa
Ejecute la aplicación en consola. Ingrese con las credenciales de administrador (admin / 1234).
Opciones disponibles: Alta de doctores, alta de pacientes y creación de citas.
